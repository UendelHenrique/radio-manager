# Axia Radio Manager

Um sistema interno para gerenciamento de rádios e dados técnicos para a Axia Energia.
Construído com Python e Flask.

## Funcionalidades
- Gerenciamento de tabelas de rádios
- Layout limpo e responsivo com tipografia Montserrat e paleta de cores corporativa (Azul Elétrico).
- Interface de login com restrição de acesso por função (Admin vs. Técnico).
- Extração de dados de manuais PDF.

## Como Executar

1. Instale as dependências:
   ```bash
   pip install -r requirements.txt
   ```
2. Execute a aplicação:
   ```bash
   python app.py
   ```
3. Acesse via navegador `http://localhost:5000`
